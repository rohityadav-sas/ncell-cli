These are labels recovered from the supplied Android app, not a complete specification of the server. The server may return a more specific responseDesc: for example, BIL2006 maps to “Product Subscription not success,” while a captured response reported a duplicate subscription request.

CLI output: plain-text errors currently explain the LGN login codes only. Other errors show their HTTP status and code. --json preserves the server response, including its message. Successful subscriptions print Subscribed to <plan name>.
